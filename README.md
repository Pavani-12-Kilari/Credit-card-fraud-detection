Credit Card Fraud Detection
Overview
This project aims to detect fraudulent credit card transactions using machine learning. It uses a dataset containing credit card transactions, with the goal of classifying each transaction as either fraudulent or legitimate. We implement the solution using a Random Forest classifier from the sklearn library.

Features
Detects fraudulent transactions

Utilizes machine learning algorithms like Random Forest

Data preprocessing and feature scaling

Model evaluation with metrics such as accuracy, precision, recall, and F1 score

Easy-to-use command-line interface for training and prediction

Requirements
The project requires the following Python libraries:

Python 3.x

pandas

numpy

scikit-learn

matplotlib

seaborn

xgboost (optional)
